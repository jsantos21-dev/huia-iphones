# HUIA IPHONE

Loja virtual estática da HUIA IPHONE.

## Publicação no Render
- Tipo: Static Site
- Build command: vazio
- Publish directory: .
- Arquivo principal: index.html

## Catálogo
O catálogo contém as opções de iPhones novos lacrados, CPO lacrados, seminovos e iPad, com modelos, armazenamento, cores e preços cadastrados a partir da tabela enviada pela loja. Variações de cor com preços distintos aparecem como opções separadas.

## Garantia e informações comerciais
- Novos lacrados/CPO: confirmar a cobertura Apple individualmente antes da venda.
- Seminovos: tabela informa peças originais e 3 meses de garantia; confirmar condições e estado do aparelho.
- Valores e disponibilidade sujeitos a alteração.

## Limitações desta versão
A vitrine utiliza uma ilustração vetorial genérica de smartphone como imagem provisória, não fotografias oficiais específicas de cada modelo. Não há integração de estoque, pedidos, WhatsApp, autenticação ou pagamentos. Configure os canais comerciais antes de publicar para vendas reais.
